## Повторение проверки

В отдельную временную папку скопировать Xpeccy+ с его DLL и каталогами `platforms`, `styles`, `imageformats`. Исполняемые файлы поместить в `Emulator`. Создать две независимые копии `config` в `Original/config` и `Rebuilt/config`, оригинальный и пересобранный диски положить соответственно в `Original/MYTHLAND.trd` и `Rebuilt/MYTHLAND.trd`.

В копиях настроек задать порты 30121 и 30122, `savepaths=no`, `pause.inactive=no`, `addboot=no`, отключить звук. Пользовательские настройки эмулятора не менять.

Из корня этой временной папки последовательно запустить:

```powershell
.\Emulator\xpeccy-plus.exe --confdir .\Original\config --machine pent --autostart --no-log .\Original\MYTHLAND.trd
.\Emulator\xpeccy-plus.exe --confdir .\Rebuilt\config --machine pent --autostart --no-log .\Rebuilt\MYTHLAND.trd
```

Для выполненного запуска использовался `Start-Process -WindowStyle Hidden`. После появления меню по локальному TCP API отправлены `pause`, `getreg PC`, `getreg SP`, `dump 4000 432`, `dump 5c00 32`. Команда `dump` принимает адрес в hex и число 16-байтных строк в decimal. Для чтения активного ПЗУ использована `dump 0 1024`. Снимки PNG построены из считанных экранных байтов, это не подставленные графические ресурсы проекта.

В начальной пробе после запроса `cpuregs` без предварительной остановки завершился тот изолированный процесс эмулятора, причина независимо не локализована. Успешная проверка использовала `pause` и отдельные запросы `getreg`. Все собственные экземпляры эмулятора после проверки закрыты.

## Область результата

Подтверждена загрузка до меню CTPAHA, перед выбором «Игра». Создание партии, бои, сохранения, загрузка сохранений и все игровые ветви не проверялись. Момент остановки двух машин различается, тождественность TRD установлена отдельно побайтовым сравнением, а совпадение экранов подтверждено считанной видеопамятью.
