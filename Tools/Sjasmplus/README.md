# SjASMPlus

Локальный экземпляр SjASMPlus 1.23.1 для сборки Strana.

Задача `Build` из [tasks.json](../../.vscode/tasks.json) напрямую запускает `Tools/Sjasmplus/sjasmplus.exe` относительно корня проекта. Сборка вызывается по `Ctrl+B`, листинг и символы записываются в [Tmp](../../Tmp).

SHA-256 исполняемого файла: `69a24ea87dd142814217a1ed7927a0386f3ed9ff8cea99ce57f7ff25a3f8c10e`.
