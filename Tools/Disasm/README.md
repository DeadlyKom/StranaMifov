# Инструменты дизассемблирования MYTHLAND

[Проект](../../README.md) · [Документация](../../Docs/README.md)

В этой папке находятся помощники для извлечения, чтения и проверки исходного образа.
Они запускаются отдельно от сборки игры. Задача `Build` из [tasks.json](../../.vscode/tasks.json) по `Ctrl+B` напрямую запускает локальный [sjasmplus](../Sjasmplus/sjasmplus.exe), а упаковка TRD выполняется через [Tools/pack.lua](../pack.lua) внутри sjasmplus.

## Расположение служебных материалов

| Папка / файл | Назначение |
| --- | --- |
| [`Disk`](Disk) | исходный образ, каталог, каркас и ключи |
| [`Extracted`](Extracted) | побайтово извлечённые файлы и секторные хвосты |
| [`Reports`](Reports) | машинные JSON/TSV-реестры и отчёты |
| [`Tmp`](../../Tmp) | временные результаты сборки, листинг `.lst` и символы `.sym` |
| [`PROJECT_FILES.sha256`](PROJECT_FILES.sha256) | контрольные суммы файлов проекта |

Читаемые руководства и индексы остаются в [Docs](../../Docs/README.md), описание сохранённой сборки — [Docs/Build.md](../../Docs/Build.md).

## Текущие инструменты

| Файл | Назначение |
| --- | --- |
| [extract_trd.py](extract_trd.py) | извлечение каталога и файлов в отдельную папку |
| [analyze.py](analyze.py) | дизассемблирование заданного диапазона оригинального файла |
| [verify_static.py](verify_static.py) | проверка переписи команд, данных и обратного представления диска без ассемблера |
| [ExportScreens.py](ExportScreens.py) | повторный экспорт экранов и портретов из оригинальных ресурсов |
| [ExportSprites.py](ExportSprites.py) | экспорт спрайтов, тайлов, шрифтов и карт с отчётом о форматах |

Для запуска нужен Python 3. `ExportSprites.py` дополнительно использует Pillow.
SkoolKit 10.0 для `analyze.py` сохранён в `Research/vendor`, включая лицензию и ROM.
Команды ниже выполняются из корня проекта.

### Проверка исходников

```powershell
python Tools/Disasm/verify_static.py
```

Проверка читает исходники, извлечённые байты и машинные реестры. Она не запускает
ассемблер и не создаёт образ TRD. Границы проверки описаны в
[VerificationLimits.md](../../Docs/VerificationLimits.md).

### Просмотр команд

```powershell
python Tools/Disasm/analyze.py 10 615E 615E 6170
```

Аргументы задают номер записи каталога, адрес загрузки, начало и конец диапазона
в шестнадцатеричном формате. В примере читается начало основного движка из записи 10.

### Извлечение в отдельную папку

```powershell
python Tools/Disasm/extract_trd.py --out "$env:TEMP/MYTHLAND-extracted"
```

Исходным образом по умолчанию служит `Tools/Disasm/Disk/original.trd`. Другой образ задаётся
через `--input`. Параметр `--out` обязателен, корень текущего проекта не является
допустимым выходом извлечения. Справка доступна через `--help`.

### Экспорт графики

```powershell
python Tools/Disasm/ExportSprites.py --project . --out Tools/Disasm/Scratch/Graphics
```

`ExportSprites.py` пишет результат в указанную папку. `ExportScreens.py`
повторно создаёт экраны, портреты и их реестр в существующих папках проекта.

## Материалы исследования

[Research/README.md](Research/README.md) описывает сохранённые сценарии исследования,
аннотации и снимки памяти. Это архив этапов восстановления исходников. Исторические
генераторы имеют прежние зависимости и пути, часть результатов уточнялась вручную.
Они не подключены к сборке и не являются автоматической цепочкой обновления проекта.

Производные изображения уже находятся в `Assets/Gfx`, поэтому второй набор этих
же изображений в архив не включён. Скрипты доставки и переоформления документации
относятся к сеансу подготовки результата и в инструменты дизассемблирования не входят.

Пути в `PROJECT_FILES.sha256` отсчитываются от корня проекта Strana.
