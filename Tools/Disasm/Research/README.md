# Исследовательский архив дизассемблирования MYTHLAND

Здесь сохранены исходные исследовательские сценарии и зафиксированные результаты анализа образа MYTHLAND.TRD. Это архив происхождения дизассемблированного проекта Strana, а не поддерживаемая последовательность повторного создания проекта. Поддерживаемые команды и их документация находятся уровнем выше, в `Tools/Disasm`.

## Состав

- Сценарии в корне исследуют каталог TRD, загрузчики, инструкции, функции, графику, структуры данных и генерируют промежуточные версии исходников и документации
- `kb` содержит этапы разбора загрузчика и BL3, промежуточные дампы памяти, сегменты и аннотации
- `loader` содержит разбор скрытого загрузчика, редактора и встроенной справки, включая обязательный снимок `hidden_memory.bin`
- `main_analysis` содержит разбор ядра игры, контракты процедур, структуры и аннотации
- `semantic` содержит сведения для смысловых имён, структур, типизированных данных и графических ресурсов
- `vendor/skoolkit-10.0` содержит использованную версию SkoolKit с исходными файлами, ROM, документацией и лицензией `COPYING`

Собственные исторические сценарии сохранены с заменой локальных абсолютных путей на относительные. Вместе с ними сохранены BIN, JSON, текстовые листинги и другие зафиксированные входы исследовательских шагов. Некоторые файлы были результатами предыдущего шага, но затем стали входами следующих. В частности, сохранённый `loader/hidden_memory.bin` нужен независимо от наличия сценария, который когда-либо создал этот снимок.

## Ограничения воспроизводимости

Переносимость исторических сценариев не обещается. Они используют собственные значения `ROOT` и `WORK` и относительные пути, которые не всегда соответствуют текущей структуре проекта. Некоторые JSON тоже содержат исторические пути, например `kb/segments.json`. Простое перемещение архива не подтверждает действительность всех путей конкретного опыта.

Не запускайте все сценарии подряд и не импортируйте их массово. Многие выполняют запись уже на верхнем уровне файла. Генераторы могут перезаписать `Main.asm`, исходники, аннотации, документацию и метаданные проекта. Порядок отдельных опытов не является готовым конвейером, а последующие ручные уточнения аннотаций могут быть потеряны при повторном выполнении раннего шага. Например, `main_analysis/annotate.py` выполняет другие файлы, а `finish_metadata.py` исторически изменяет признаки проверки сборки. Запуск такого сценария сам по себе не подтверждает сборку.

Архивные генераторы документации относятся к состоянию исследования, в котором часть документов имела расширение `.txt`. Их нельзя массово выполнять поверх актуальной документации Markdown. Для конкретного повторного опыта сначала изучите код, все входы, выходы и пути, затем используйте отдельную рабочую папку.

Переносимые версии помощников `analyze.py` и `extract_trd.py` размещаются уровнем выше этого архива. Архивные одноимённые файлы оставлены для сравнения с исходным исследованием. SkoolKit используется из этого архива. Сценарии обработки изображений также требуют Pillow, эта зависимость сохранена.

## Что исключено

Кэши Python исключены. Папка `semantic/graphics` исключена, поскольку это 2027 производных файлов, продублированных в `Assets/Gfx` проекта. Скрипты копирования проекта, сбора результатов сборки и проверки доставки, их отчёты, журналы сборки и папка `md_conversion` не относятся к исследованию дизассемблирования и сюда не включены. Новые инструменты преобразования Markdown этого этапа тоже не включены.

Перечень скопированных файлов с SHA-256 и отдельный отчёт staging сопровождают передачу этого архива. Сохранение сценария или дампа не означает, что игра была полностью проверена запуском либо что каждый исторический сценарий поддерживается как самостоятельная команда.
